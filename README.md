# QA Portfolio

Este repositorio reúne proyectos y ejercicios prácticos enfocados en Software Quality Assurance.

Incluye documentación real de testing sobre una aplicación mobile propia, un proyecto académico en equipo y un proyecto de automatización Web/API, cubriendo todo el ciclo: estrategia, planificación, ejecución manual, exploratoria, automatización y reporte de bugs.

---

### 📂 Proyecto Doo It — Manual Testing

Testing funcional y exploratorio sobre Doo It!, una app de rutinas de entrenamiento 100% offline que desarrollé en solitario (React Native / Expo).

| Carpeta                | Contenido                             |
| ---------------------- | ------------------------------------- |
| `Test Plan`            | Alcance y planificación del testing   |
| `Manual Test Cases`    | Casos de prueba funcionales           |
| `Exploratory Testing`  | Sesiones de testing exploratorio      |
| `Bug Reports`          | Bugs encontrados y documentados       |
| `Regression Checklist` | Checklist de Regression Testing       |
| `Test Summary`         | Resultados y métricas del testing     |
| `Improvements`         | Oportunidades de mejora identificadas |

### 📂 Proyecto Rescuetrack — Testing Funcional (Web & Móvil)

Testing funcional de un sistema de gestión de vehículos de emergencia.

Proyecto académico realizado en equipo.
Plan de pruebas funcional, de integración, carga y stress sobre los módulos de login, gestión de usuarios y vehículos, mantenciones, notificaciones y reportes de costos — en sus versiones web y móvil.

| Plataforma | Casos                             |
| ---------- | --------------------------------- |
| Web        | 30 (28 OK · 2 Obsoletos)          |
| Móvil      | 23 (12 OK · 4 NOK · 7 pendientes) |

En ambas plataformas, cada defecto detectado se clasificó por severidad (leve, medio, grave) para su seguimiento. Como parte del equipo, participé en la ejecución y documentación de los casos de Registro de usuarios, Vehículos y Reportes de costos en la versión web, y de Login, gestión de mantenciones, notificaciones y visualización de costos en la versión móvil.
