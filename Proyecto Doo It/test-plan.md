# Test Plan - Doo It!

## Objetivo

Verificar que las principales funcionalidades de Doo It! funcionen correctamente antes de una nueva versión de la aplicación.

## Funcionalidades incluidas

- Creación de rutinas
- Entrenamientos de fuerza
- Entrenamientos de cardio
- Temporizadores
- Historial
- Estadísticas
- Persistencia
- Compartir rutinas
- Notificaciones
- Sistema de medida
- Multi Idioma
- Perfil y cálculo de IMC

## Fuera de alcance

- Pruebas de infraestructura en servidor, debido a que la aplicación funciona de forma local.
- Rendimiento en todos los dispositivos Android.

## Ambiente de prueba

- Aplicación móvil React Native
- Android.
- Datos almacenados localmente.

## Criterios de entrada

- Build instalable disponible.
- Funcionalidades principales implementadas.
- Datos de prueba definidos.

## Criterios de salida

- Todos los casos críticos ejecutados.
- Ningún defecto crítico abierto.
- Defectos de severidad alta identificados y documentados.
