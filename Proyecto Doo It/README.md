# QA Documentation

Esta sección contiene la documentación de Quality Assurance aplicada a Doo It!

El objetivo es documentar y ejecutar un proceso de testing sobre la aplicación Doo It!, incluyendo diseño de casos de prueba, pruebas exploratorias, gestión de defectos, regresión y en un futuro pruebas automatizadas.

## Scope

Las pruebas cubren principalmente:

- Creación de rutinas
- Entrenamientos de fuerza
- Entrenamientos de cardio
- Temporizadores
- Historial
- Estadísticas
- Persistencia
- Funcionamiento offline
- Notificaciones
- Compartir rutinas
- Cambio de idioma
- Cambio de sistema de medida
- Perfil y cálculo de IMC
